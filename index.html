Before you begin

This is a blinded study. Until you have submitted all of your judgments, please do not look at:

  • strategy, controller or method names of any kind;
  • annotated, labelled or diagnostic versions of these videos;
  • performance metrics, score tables, success rates or result files;
  • any file describing which option corresponds to which method.

Knowing any of this makes your judgments unusable. If you see such information by accident, stop and tell the study coordinator rather than continuing.

Study instructions — please read once before starting
  1. You will see 9 comparison videos. Each shows two robot behaviours performing the same task from the same starting state, side by side. Option 1 is the left video; Option 2 is the right video.
  2. Watch each video all the way through before answering. The answer form stays locked until playback has covered the whole clip. You may replay it as often as you like, and change playback speed.
  3. Judge each pair three times, once under each evaluation context: balanced, safety priority, and efficiency priority. The contexts are independent — a pair may legitimately come out differently under each one.
  4. For every judgment give a preference, a confidence rating, at least one reason, and the task stage that most influenced you. A short written observation is welcome.
  5. Choose Tie when the two behaviours are approximately equally desirable. Choose Incomparable when each has important advantages and no defensible overall ranking exists — these are different answers, so please do not use one for the other.
  6. Answers save automatically in this browser as you go. You can leave and come back with the same reviewer ID on the same browser. Export a backup file if you need to move to another machine.
  7. Judge only what you can see in the video. There is no hidden ground truth you are supposed to recover, and there is no expected answer.

This browser is blocking local storage, so answers cannot be saved automatically. Export a JSON backup regularly, or switch to a normal (non-private) browser window.
